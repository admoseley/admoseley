## 💫 About

I build the tools I need and ship them properly — issue, branch, pull request,
Terraform, CI, deploy. Most of my work lives in private repos: client sites,
internal tooling, and infrastructure for a handful of small businesses.

Lately that means a lot of AI-assisted development, Azure migrations, and
replacing third-party services I no longer want to depend on.
